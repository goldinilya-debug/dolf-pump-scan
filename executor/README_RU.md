# Исполнитель BingX: торгует по стратегиям на мини-ПК с Windows

## Что делает программа

Программа сама торгует бессрочными фьючерсами USDT-M на бирже BingX. Сначала только на демо-счёте с виртуальными деньгами (VST).

- **Основная стратегия — S06, моментум за 30 дней на BTC и ETH.** Это та же логика, что в бумажном боте `bot/paper_bot.py`. Каждый день после закрытия дневной свечи в 00:00 UTC (в 00:05 UTC, с запасом 5 минут) программа сравнивает цену закрытия с ценой 30 дней назад.
  - Если цена выросла, открывается LONG. Если упала, открывается SHORT.
  - Если направление сменилось, программа закрывает позицию и открывает её в другую сторону.
  - Стоп ставится на расстоянии 3 ATR (средний дневной размах за 14 дней).
  - Риск 1% от половины баланса на каждую монету.
- **Сразу после входа на бирже ставится стоп-ордер** (STOP_MARKET, закрывает всю позицию). Каждую минуту программа проверяет, что он на месте. Если стопа нет, она ставит его заново.
- Маржа изолированная, плечо не больше 3x.
- Обо всём программа пишет в Telegram: запуск, сигнал, ордер, стоп, тейк, ошибки, остановки.

Стратегии подключаются как модули из папки `strategies/` и включаются флагами в `.env`:

| Флаг | Стратегия | Состояние |
|---|---|---|
| `STRAT_S06=1` | Моментум 30д, BTC+ETH, раз в сутки | **включена, проверена** |
| `STRAT_DONCHIAN=0` | Дончиан 4h (эталон B из paper_bot) | перенесена и проверена, выключена |
| `STRAT_STAR=0` | «Звезда» 4h, 15 монет, тейк 1R | перенесена, **не сверена** с бэктестом, выключена |
| `STRAT_PUMPS=0` | Шорт пампов DOLF (сетка +1/+3/+5%, цели 1.5/2/3R, безубыток) | только заготовка, включить нельзя |

Движок уже умеет частичные тейки и перенос стопа в безубыток. Это нужно «Звезде» и будущим «Пампам». Лестницу лимитных входов для «Пампов» движок пока не умеет.

## Защита

- **Файл `STOP` в папке** (пустой, с любым содержимым) — новых входов нет. Удалили файл — входы снова разрешены.
- **Команды в Telegram** (принимаются только из вашего чата `TG_CHAT`):
  - `/status` — баланс, позиции, стопы, остановки;
  - `/stop` — запретить новые входы. Позиции и стопы остаются как есть;
  - `/resume` — снова разрешить входы;
  - `/closeall`, потом `/confirm_closeall` в течение 2 минут — закрыть все позиции бота по рынку и снять его ордера.
- **Дневной лимит.** Если equity упала на 3% с начала суток UTC, новые входы запрещены до следующих суток.
- **Лимит просадки.** Если equity упала на 10% от пика, новые входы запрещены до команды `/resume`.
- **Общие лимиты на все стратегии:** не больше 4 позиций одновременно, суммарный открытый риск не больше 3% equity. У каждой стратегии свой бюджет: `RISK_<ИМЯ>`, `CAPITAL_<ИМЯ>`, `MAXPOS_<ИМЯ>`.
- **На одной монете одновременно может быть только одна позиция.** Если монету уже держит одна стратегия, другая её не трогает.
- **После перезапуска программа не входит второй раз.** Каждому ордеру она даёт свою метку (clientOrderId), запоминает состояние в `state.json` и сверяет его с биржей.
- **Без `CONFIRM_LIVE=YES` реальный счёт не запустится.**

## Установка (один раз)

1. Поставьте Python 3 с https://www.python.org/downloads/ и при установке отметьте «Add python.exe to PATH». Поставьте Git: https://git-scm.com/download/win
2. Откройте «Командную строку» (Win+R → `cmd`) и выполните:
   ```
   cd %USERPROFILE%
   git clone https://github.com/goldinilya-debug/dolf-pump-scan.git
   cd dolf-pump-scan\executor
   py -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
   (Если папку `executor` скопировали вручную, перейдите в неё и выполните две последние строки.)
3. Сделайте файл настроек и откройте его:
   ```
   copy .env.example .env
   notepad .env
   ```
4. Заполните в Блокноте:
   - `BINGX_API_KEY` и `BINGX_API_SECRET`. Создайте ключ на BingX: Профиль → API Management. Права: чтение и торговля фьючерсами, **без вывода средств**. Лучше привязать ключ к домашнему IP.
   - `TG_TOKEN`. Сделайте **отдельного** бота в @BotFather. Если взять бота, которого уже опрашивает другая программа, команды будут конфликтовать.
   - `TG_CHAT`. Напишите новому боту `/start`, откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите число из `"chat":{"id":...}`.
   - `MODE=demo` пока не трогайте.
   - Сохраните файл: Ctrl+S.

## Проверка

```
.venv\Scripts\python executor.py --check
```
Команда только читает данные. Она показывает время сервера, баланс, позиции и ордера и шлёт тестовое сообщение в Telegram. В конце должно быть `CHECK OK`.

```
.venv\Scripts\python executor.py --dry-run
```
Команда показывает текущий сигнал, размер позиции и стоп, но **ордеров не ставит**.

Тесты работают без интернета и без ключей, примерно 20 секунд:
```
.venv\Scripts\python -m unittest discover -s tests
```

## Запуск

Двойной клик по `start_bot.bat`, или в командной строке:
```
start_bot.bat
```
Окно должно оставаться открытым. Если программа упадёт, `start_bot.bat` перезапустит её через 30 секунд. Остановить: Ctrl+C. Стопы на бирже при этом остаются.

**Важно.** При первом запуске программа сразу встанет в позицию по текущему сигналу, так же как держит позиции бумажный бот. Посмотрите заранее, что покажет `--dry-run`.

## Автозапуск при включении ПК

В папке `executor` откройте PowerShell (Shift + правый клик → «Открыть окно PowerShell здесь») и выполните:
```
powershell -ExecutionPolicy Bypass -File .\install_task.ps1
```
Программа будет стартовать, когда вы входите в Windows. Чтобы она стартовала сразу при включении, ещё до входа, запустите PowerShell от администратора и добавьте `-AtStartup`. Удалить задачу: `-Remove`.

Можно и вручную: «Планировщик заданий» → «Создать задачу».
- Триггер: «При входе в систему» (или «При запуске»).
- Действие: `start_bot.bat`, поле «Рабочая папка» — папка `executor`.
- Параметры: «Перезапускать при сбое» каждую 1 минуту до 999 раз; снять галочку «Останавливать задачу, выполняемую дольше…».
- Чтобы ПК не засыпал: Параметры → Система → Питание → «Спящий режим: никогда».

## Где что лежит

- `logs/executor.log` — подробный журнал (до 10 файлов по 2 МБ).
- `state.json` — память программы. Не удаляйте его во время работы. Если всё же удалите, программа найдёт свои позиции на бирже и снова возьмёт их под контроль.
- `strategies/` — стратегии: `s06_tsmom.py`, `donchian.py`, `star.py`, `pumps.py`, общий интерфейс `base.py`.

## Переход на реальный счёт (не раньше чем через 3 месяца демо)

В `.env` поставьте `MODE=live` и `CONFIRM_LIVE=YES`, ключ возьмите от реального счёта. Без `CONFIRM_LIVE=YES` программа откажется запускаться.
